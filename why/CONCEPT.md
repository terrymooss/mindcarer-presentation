# 마음챙김 | WHY 캠페인 — 브랜드 광고 제작 제안 v0.1

> 기존 `/v1/`은 약국·약사 사용 방법 소개 영상으로 보존합니다. 본 프로젝트는 기능을 나열하는 설명 영상이 아닌, **왜 지금 약사 중심의 상담 플랫폼이 필요한가**를 설득하는 독립 광고입니다.

## 전략 한 문장

**“약을 쉽게 살 수 있는 시대. 제대로 복용하도록 돕는 약사는 더 중요합니다.”**

문제의 주체를 ‘특정 형태의 약국’이 아니라 **충분한 상담 없이 의약품을 선택하거나, 기존 복용 정보를 확인하지 못하는 상황**으로 설정합니다. 소비자의 편의성·가격 접근성을 비난하지 않고 ‘안전하게 선택할 권리’와 ‘약사 상담의 가치’를 강조합니다.

## 대상과 핵심 혜택
- **약국장:** 가격 경쟁이 아닌 전문 상담·맞춤 건강관리·관계의 지속성으로 차별화. 운영 기록과 후속 관리의 연결.
- **근무 약사/상담 약사:** 건강검진·복용약·영양제·생활습관 정보를 한곳에서 살펴보고, 복용 성분 중복·주의정보를 **상담 참고자료**로 활용. 상담 기록을 다음 상담까지 연결.
- **고객:** 제품을 하나 더 권하는 것이 아니라, 무엇이 필요하고 무엇을 조심해야 하는지 전문가와 확인하는 경험.

## 광고 카피 후보
1. **약의 가격은 비교할 수 있습니다. 당신에게 맞는 약인지, 누가 확인할까요?**
2. **약을 파는 곳에서, 건강을 살피는 곳으로.**
3. **더 많이 판매하는 것이 아니라, 더 정확하게 확인하는 것.**
4. **AI가 정리하고, 약사가 판단합니다.**
5. **약사가 고객을 기억하는 약국. 마음챙김.**
6. **배송 이후에도, 상담은 계속되어야 하니까.**

메인 권장 카피: **“약이 손에 닿는 속도보다, 약사가 고객을 이해하는 깊이.”**
마지막 서명: **“약사의 전문성은 화면 너머에서도 이어집니다. 마음챙김.”**

## 이야기 구조

1. **문제 제기 (약 0–35초):** 대량 진열·가격표·빠른 구매·배송 아이콘. “편해졌지만, 누가 복용약과 중복성분을 물어볼까요?” 특정 업체 실명이나 비난은 사용하지 않음.
2. **반전 (약 35–60초):** ‘구매’가 아니라 ‘복약 질문’에 화면이 정지하고, 약사의 질문 한 문장이 나타남.
3. **해결 (약 60–145초):** 마음챙김의 고객 건강정보 통합 → AI 분석 요약·주의 성분 검토 → 약사의 전문 상담·맞춤 영양 설계 → 상담 기록·후속관리.
4. **약국의 변화 (약 145–185초):** 매번 새로운 판매가 아닌 이어지는 건강 관계. 약국장/약사/고객의 상호 가치.
5. **행동 유도 (약 185–200초):** 실제 로고와 `https://pulsenall.com` 접속 QR. **“마음챙김 파트너 약국과 함께 시작하세요.”**

**권장 러닝타임:** 핵심 광고 75–100초 / 전체 브랜드 필름 180–210초. 정확한 컷 길이는 새 Moonjung 녹음 길이에 맞춰 결정. 기존 `v1`의 63컷·음성은 수정하지 않음.

## 크리에이티브 방향
- **형태:** 전체 화면 모던 모션그래픽. 첫 30초는 낮은 채도·속도감 있는 상징 그래픽 → 약사의 질문과 함께 따뜻한 녹색으로 전환.
- **구성:** 한 화면 한 문장 / 한 가지 중심 오브젝트 / 2~3단계 모션. 반복적인 카드형 UI 금지.
- **그래픽:** 가격표·쇼핑카트·택배 상자에서 시작 → 약물·영양제 캡슐 겹침 → 약사의 검토 렌즈 → 고객 약력 그래프·상담 타임라인 → 커뮤니티 약국의 지속 연결.
- **휴대폰·QR:** 필요할 때만 사실적으로; QR은 장식이 아닌 `https://pulsenall.com` 실물 코드.
- **한글:** `word-break:keep-all`, 안전영역 확보, 세로/가로 전환 시 상호 겹침 자동 검사.
- **레이어:** 선은 원형 노드·텍스트·인물 그래픽 뒤, 상담 연결선은 말풍선 외부에서 곡선으로 이어지도록.
- **음악:** 문제 장면의 건조한 타격감 → 해결 장면의 따뜻한 리듬. 새 오디오 생성·상업적 배포는 별도 확인 후 수행.
- **인터랙션:** 처음에 **핵심 내용 / 전체 내용** 선택, 클릭 직후 내레이션 재생, 재생 종료 후 다시 보기 / 다른 분량 선택.

## 반드시 지킬 표현 기준
- ‘창고형 약국 때문에 과복용이 발생했다’는 일반적인 인과관계 주장 **금지**. ‘상담·복용정보 확인이 부족하면 중복·오남용 위험이 커질 수 있다’로 표현.
- ‘약 배송은 불법이다/무조건 위험하다’ 등 단정 **금지**. 한국의 제도는 대상과 시행 시기에 따라 달라지며, 배송 편의와 복약지도 안전은 함께 논의할 필요가 있음.
- 마음챙김이 의약품을 비대면 배송한다는 인상을 주지 않음. 조제용 의약품의 배송과 약국의 맞춤 영양제 소분·배송은 엄격하게 구분.
- ‘약사 대체 AI’, ‘부작용 100% 예방’, ‘매출 N% 상승’, ‘상담 없이 자동 설계’ 등의 과장 주장 **금지**.
- 제품·고객 정보는 연출용 가상 데이터 사용. 서비스 실제 구현 범위는 공개 전 앱 코드·관리자/약사 UI로 다시 검증.
- 대한약사회 설문의 ‘81.6%’는 **창고형 약국 인근 535개 약국 조사 응답자의 인식**일 뿐 전체 약사/환자 비율이 아니므로 본편에서는 숫자 사용하지 않음.
