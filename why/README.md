# 왜 지금, 마음챙김인가? — 약사 전문성 브랜드 캠페인

**별도 광고 프로젝트 기획 자료**입니다. 기존 사용 가이드 영상 `/v1/`의 코드는 변경하지 않습니다.

- 목적: **왜 약국장과 약사가 마음챙김을 사용해야 하는가**를 감성적·근거 기반으로 설명
- 주제: 약을 판매하는 약국을 넘어 **약사 상담과 환자 안전을 중심에 두는 약국**
- 메인 카피: **약을 쉽게 살 수 있는 시대. 제대로 복용하도록 돕는 약사는 더 중요합니다.**
- 핵심 메시지: **AI가 정리하고, 약사가 판단합니다.**
- 형태: 완성 시 기존 `v1`과 독립적인 **풀스크린 HTML 브랜드 광고** (`/why/` 예정)
- 구성: **핵심 광고(약 80–105초)** / **전체 브랜드 필름(약 3분 20초)** 선택형
- 현재 단계: **크리에이티브 브리프 및 컷별 콘티 v0.1**. HTML·내레이션·광고 게시 전 표현 검수는 다음 단계.

문서:
- [CONCEPT.md](./CONCEPT.md) — 포지셔닝, 메시지, 디자인 가이드, 검증 근거
- [STORYBOARD.md](./STORYBOARD.md) — 약 18컷 전체 콘티, 핵심 버전과 티저 편집안

본 캠페인은 창고형 약국 전체가 과복용을 유발한다고 단정하지 않습니다. **상담과 약력 확인이 부족한 환경에서 가능한 위험을 강조**하면서 편의·접근성의 긍정적 측면을 부정하지 않습니다.
