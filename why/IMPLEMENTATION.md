# WHY 브랜드 캠페인 — HTML 모션 시제품 v0.2

## 현재 구현
- 정식 소개 영상 `/v1/`과 독립적인 `/why/` HTML.
- 사용자 선택: **핵심 광고 13컷(임시 타임라인 1:30)** / **전체 브랜드 필름 18컷(3:21)**.
- 18개의 개별 벡터 장면, 16:9 풀스크린 SVG, 장면별 모션 효과.
- 시작 모달, 종료 후 다시 보기/다른 분량 선택, 재생·일시정지·탐색·자막·전체 화면·장면 목록.
- 브라우저 탭과 시작 화면: 기존 `../v1/brand-logo-icon.png` 공식 로고 재사용.
- 엔딩 QR은 `https://pulsenall.com`으로 연결하는 실제 SVG QR (`qr-pulsenall.svg`).
- 음성 파일·음악 파일 없음. 새 Typecast Moonjung 나레이션 생성과 크레딧 사용은 아직 실행하지 않았음.
- 따라서 **현재는 무음 모션 시안**으로 대본/장면/화면 구성이 검수 목적이며 대외 광고 공개 전 별도 최종 확인이 필요합니다.

## 테스트
- Chromium: 18컷 × 두 시점 = 36프레임 SVG 텍스트 화면 이탈 0건, 텍스트끼리 겹침 0건, JS 오류 0건.
- 13컷/18컷 재생/전환/종료 대화상자 정상.
- 스마트폰 세로 390×844, 가로 844×390 첫 화면 모두 사용 가능.
- QR SVG를 실제 이미지로 렌더링하여 `https://pulsenall.com` 인식 확인.

## 다음 제작 단계
1. 약국장/약사 타깃의 카피·법적 표현 검수(특히 창고형 약국, 의약품 배송·복약지도 관련).
2. Moonjung 음성 성우 스타일 승인 → Typecast 새 합성 (비용/크레딧 별도 승인 후).
3. 실제 음성 길이에 맞춰 컷 길이를 교체하고 장면 전환 자동 동기화.
4. 효과음·배경음악 저작권 조건 확인, 배포 전 전체 재검수.

## 공개 시 유의 사항
중복 성분 시각화는 모식적 예시이며 개별 환자의 실제 위험도나 진단 결과를 표현하지 않습니다. 처방의약품 배송과 맞춤 영양제 배송을 혼동시키지 말 것. AI 분석은 약사의 전문 판단을 대신하지 않습니다.
