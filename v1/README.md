# 마음챙김 인터랙티브 소개 영상 — v1

기반: 마음챙김 Fullscreen Motion 6.1, 총 63컷, 11챕터, Moonjung TTS.

GitHub Pages: /v1/ 또는 /v1/index.html 에서 직접 재생합니다.

기존 6.1 시각 디자인과 기능을 유지하되 음성 파일은 페이지 로딩 및 저장소 용량을 줄이기 위해 MP3 모노 96kbps로 변환했습니다. 동영상(mp4)은 포함하지 않습니다.

운영 수치/고객정보는 모식도입니다. 원본 음성의 Typecast 상업적 공개 이용 조건은 별도로 확인해야 합니다.

파일: index.html, 디자인/장면 JS, favicon brand-logo-icon.png, audio/CUT_01.mp3~CUT_63.mp3. API 토큰이나 개인 고객 데이터는 포함되지 않습니다.
