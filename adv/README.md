# 약사의 전문성이 더 중요해지는 시대 — 약국·약사 대상 캠페인 (adv)

**약국·약사에게 “왜 마음챙김을 써야 하는가”를 특장점과 위기 진단으로 설득하는 광고 페이지입니다.**

- 대상: **약국장 · 근무 약사 · 상담 약사** (B2B)
- 메인 카피: **“약을 쉽게 살 수 있는 시대. 제대로 복용하도록 돕는 약사는 더 중요합니다.”**
- 핵심 메시지: **AI가 정리하고, 약사가 판단합니다.**
- 차별점: **약사 역할 축소 논쟁(창고형 약국 · 의약품 배송)을 정면으로 다루고, 대한약사회가 제기한 위기를 해결 과제로 제시**합니다.
- 페이지: **https://intro.pulsenall.com/adv/** (GitHub Pages)
- 형태: `index.html` **단일 파일**(CSS·JS 인라인). 별도 빌드·의존성 없이 바로 열립니다.

## 주의

- 인용 수치는 조사 대상·시점이 제한된 자료입니다. **창고형 약국이 과복용의 원인이라고 단정하지 않으며, 특정 업체를 지목하지 않습니다.**

- 운영 수치·고객 정보는 연출용 예시입니다. 실제 서비스 기능 범위는 공개 전 앱·관리자 UI로 재검증이 필요합니다.
