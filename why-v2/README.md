# 마음챙김 WHY — 시네마틱 브랜드 필름 V2 (첫 HTML 시안)

기존 `/v1/` 소개 영상과 `/why/` 인포그래픽 광고는 **변경하지 않았습니다.**

## 시청
- https://intro.pulsenall.com/why-v2/
- 최초 접속 시 **핵심 광고 13컷 (임시 약 1:28)** / **전체 브랜드 필름 18컷 (임시 약 2:57)** 선택
- 장면 이동, 자막, 전체화면, 다시 보기, 배경음 ON/OFF
- 현재 시네마틱 배경음은 브라우저 자체 오실레이터로 만든 **임시 사운드**입니다.
- **Moonjung TTS 음성, 실사 영상, 배포용 MP4 미생성. 유료 크레딧 사용 없음.**

## 스토리
위기(창고형 약국의 가격 중심 경쟁과 약 배송 논쟁) → 약사의 전문성 위축 우려 → 약사회의 노력과 현장 변화 → 환자의 복약 질문 → 마음챙김의 건강정보 정리·AI 보조·약사 판단 → 신뢰의 약국.

창고형 약국이 과복용의 원인이라고 단정하지 않고 **상담·약력 확인이 없을 때 가능한 중복 복용·과다 섭취 위험**을 말합니다.
약 배송은 편의와 안전한 복약지도 모두를 중요하게 다룹니다.
실사 대신 이 버전은 **원본 SVG 기반의 스타일화된 시네마틱 모션 시안**으로, 실제 사건이나 인물을 재현했다고 주장하지 않습니다.
